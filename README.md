# Clementine Coder
A coding ancilla that helps building prototypes, code reviews, analyst

## Overview
Clementine Coder is an AI coding assistant that can be locally deployed designed to help developers write code faster and more efficiently. It comes in two flavors:

### 🎯 Clementine CLI
The command-line interface version of Clementine that integrates directly into your terminal environment.

### 💬 Clementine Chat
The web-based chat interface that provides a conversational coding experience.



## Requirements
* Mac machines with big memory

# Create and use virtual env:
    python -m venv <name_env>
    source <name_env>/bin/activate

# Install dependencies
    pip install -r requirements.txt
